# World Sports Group — Official Website

A modern, premium corporate website for **World Sports Group (WSG)**, showcasing its sports ecosystem, events, players, media production, PR, and sponsorship capabilities.

## 🏆 About World Sports Group

World Sports Group is a sports-focused organization working across events, athletes, media, entertainment, public relations, television production, and sponsorship.

The website presents WSG's services, sports properties, featured players, events, and brand partnerships through a premium digital experience.

## ✨ Features

* Premium sports-focused UI
* Fully responsive design
* Modern corporate website experience
* Hero section with animated visuals
* Sports events showcase
* Featured players section
* Sports properties and initiatives
* TV & media production services
* PR and communications
* Sponsorship opportunities
* Brand partnerships
* Interactive sections and animations
* Mobile-optimized layout
* Modern dark sports aesthetic

## 🚀 Run Locally

### Prerequisites

Make sure **Node.js** is installed on your computer.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The terminal will display the local development URL.

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
